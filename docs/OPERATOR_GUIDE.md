# 现场工作人员操作指南

1. **prepare**：确认赛事名称、6 支队伍和匿名评委人数。
2. 生成匿名评分码，并通过安全方式分别发给评委。
3. 点击“开始评分”，进入 **scoring**。
4. 评委使用评分码进入评分页；评分范围为 0.0—10.0 分，保存后可刷新恢复。
5. 后台确认完成数量达到全部评分要求。
6. 点击“锁定评分并生成结果”，进入 **locked**。此时评委端只读，成绩大屏暂不显示分数。
7. 主持人确认现场准备完成后，点击“公布最终成绩”，并进行二次确认，进入 **published**。
8. 点击“打开成绩大屏”，现场展示一等奖 1 支、二等奖 2 支、三等奖 3 支及最终平均成绩。

注意：锁定和公布都是不可逆的现场操作；如需重新演示，请仅在 DEMO 模式使用“重置比赛”。
